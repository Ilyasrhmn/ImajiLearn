# Dashboard foundation

Guru SD menjadi pengguna utama. Dashboard memperlihatkan materi dengan navigasi datar, ruang yang lapang, satu judul per bagian, dan karakter alat tulis. Gunakan kertas hangat, tinta gelap, terracotta, sage, dan Nunito Sans. Ikon tindakan memakai Lucide. Jangan menambah sidebar, statistik contoh, atau teks pendukung berlapis.

Tahap pertama hanya mencakup halaman `/dashboard`, keadaan kosong Materi/Arsip, dan layout responsif. Tombol unggah sengaja dinonaktifkan sampai alur upload diimplementasikan. Belum ada autentikasi, backend, atau data guru; jangan menampilkan pengguna seolah sudah login.

Tahap selanjutnya: upload dan penyimpanan materi, folder mapel, kemudian generator per media. Catat setiap fitur sebagai commit terpisah sesuai pekerjaan nyata. JSX tetap digunakan untuk kedua aplikasi.
